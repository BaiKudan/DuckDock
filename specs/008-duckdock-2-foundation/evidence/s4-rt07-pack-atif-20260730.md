## Frozen boundary

- API operations: `createPackImport`, `getPackImport`, `finalizePackImport`.
- Namespace and Runtime come only from `execution.write`
  ReporterCredential.
- Same Runtime + Pack ID + canonical manifest + Pack checksum is a replay.
- Same Pack ID with changed validated content is persisted as QUARANTINED and
  returns 409.
- Source Pack keys and extracted payload keys are content-addressed.
- Trust is always `CHANNEL_AUTHENTICATED + IMPORT`; checksum is not
  attestation.
- Import only links a reliably correlated existing Run. It does not synthesize
  an offline Run from untrusted manifest data.
- MySQL and Outbox never contain archive/ATIF content, entry bodies or raw error
  text.

The dependency-free codec recognizes the official ATIF v1.x line through
`ATIF-v1.7`. It only validates the bounded envelope during Foundation; it does
not normalize trajectory content or introduce a Harbor runtime dependency.
The upstream format documents ATIF as JSON and v1.7 as the current schema:
<https://www.harborframework.com/docs/agents/trajectory-format>.

## Preflight and privacy

Before any final payload object, Artifact row or Outbox event is produced:

1. whole Pack size and SHA-256 match;
2. ZIP entry paths are normalized relative POSIX paths;
3. absolute/traversal/backslash/control paths, duplicate normalized entries,
   directory/symlink/encrypted entries and unexpected files are rejected;
4. entry count, per-entry bytes, total uncompressed bytes and compression ratio
   are bounded;
5. embedded strict manifest canonical hash matches upload initialization;
6. every declared payload size and SHA-256 matches;
7. ATIF schema and declared version agree;
8. Secret Canary and unauthorized content are rejected before final storage;
9. Run/session/deployment/trace signals resolve to one Runtime-scoped Run.

Foundation has no Namespace content-authorization object yet. Therefore a
producer-declared policy/redaction receipt cannot authorize message, reasoning,
Tool I/O or observation content; such Packs quarantine. This is fail-closed.

## Deliberate non-claims / follow-up

RT-07 does **not** claim resumable multipart, durable batch ack cursor, ATIF
export, evaluation replay or full DD-C3. Those remain in NEXT-003/RT-08; the
capability descriptor must not advertise them early.
